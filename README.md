# Assessly

**Assessly** is an Online Exam Management & Self-Assessment Platform designed to streamline academic department management, practice questions, timed exams, student entitlements, and manual payment verification (Telebirr & Bank transfers).

## Project Structure

```text
assessly/
├── backend/          # Node.js + Express + TypeScript + Prisma ORM API
└── frontend/         # Next.js + React + Tailwind CSS Web Application
```

## Quick Start

### Backend
```bash
cd backend
npm install
npm run db:generate
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
